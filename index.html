Projects

Automatic Air Humidifier

2026 · Team Leader

A smart system that activates using a temperature sensor.

View project

Overview

A smart temperature and humidity control system built using an Arduino microcontroller and C++. The system automatically activates a spray module when the temperature exceeds a set limit and turns it off when the temperature returns to normal.

How it works

The LM35 sensor measures the room temperature, and the Arduino reads the data. The LCD shows the temperature in real time, while a potentiometer adjusts the screen brightness. If the temperature gets too high, a red LED turns on, the buzzer makes a sound, and the spray module starts working. When the temperature returns to the normal range, the spray module turns off.

My role

As the team leader, I assigned tasks to each team member, coordinated the circuit design and programming, and ensured that the team worked together throughout the project.

Result

Successfully developed and simulated an automatic temperature control system. This project improved practical skills in Arduino programming, circuit design, teamwork, and problem-solving.

Fun Fact

The project started from scratch, from designing the circuit and writing the code independently to assembling the components. The process also involved calculating component costs, designing the casing, and building it using available materials, including recycled plastic bottles. It was a hands-on experience in turning an idea into a working prototype with limited resources.

Automatic Toren

2025 · Team Leader

A smart system that uses an Ultrasonic Distance Sensor to automatically activate the toren based on distance.

View project

Overview

An automatic toren system built using an Arduino microcontroller and C++. It helps control the water pump automatically, so there is no need to turn it on or off manually.

How it works

The ultrasonic sensor measures the water level by detecting the distance between the sensor and the water surface. The Arduino processes the data and controls the DC motor to turn the water pump on or off based on the water level. The system was designed and simulated using Tinkercad.

My role

As a team member, I helped develop the circuit design and Arduino program to make the water pump work automatically.

Result

Successfully designed and simulated an automatic toren system using Arduino and an ultrasonic sensor. This project addresses a common problem where people forget to turn off the water pump when the tank is full, causing water wastage. By combining a sensor, a motor, and an Arduino, the system automates water pump control, reduces the risk of overflowing, and makes daily tasks easier.
